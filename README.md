# 拾星 · 第 07 阶段：发布校验

## 运行

解压后使用 Chrome 打开 index.html，无需安装依赖或服务器。保留 assets 相对路径。

## 本阶段新增

表单、错误提示、照片上传和地图选址。

## 验收

合法发布后出现在详情及列表；错误输入不新增；刷新尚不保存。

## 累计能力

1. 入口、脚本、样式与最小运行说明
2. 浅色星空主题、北斗导航、页面容器
3. 校园夜景地图、五条示例信息、照片便签、四色状态星
4. 关键词、类别、地点、日期、状态组合筛选
5. 便签到详情、物品特征、发布者和核对提示
6. 三个账号切换、头像与各自我的发布
7. 表单、错误提示、照片上传和地图选址

## 限制

刷新后数据恢复示例；尚未实现持久化。
