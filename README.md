# 拾星 PickStar

拾起散落星辰，归还赠以玫瑰。

校园失物招领课程演示项目，实现“发布信息 → 浏览或搜索 → 查看详情 → 联系发布者 → 更新状态”，并提供校园星图、三账号模拟登录和玫瑰致谢。

## 下载与运行

1. 在主仓库选择 `main`，点击 `Code → Download ZIP`。
2. 完整解压 ZIP，不要直接在压缩软件内打开网页。
3. 使用 **Google Chrome** 打开项目根目录的 `index.html`。
4. 保持 `app.js`、`styles.css` 和 `assets` 的相对位置不变。

运行网页无需 Node.js、安装依赖或启动服务器。本地资源齐全时可离线展示；系统字体不同可能影响字形。

## 操作指南

### 1. 模拟登录与发布

顶部切换 Nova、小面包、星星同学，无需注册或密码。进入发布页选择“我丢失了”或“我捡到了”，填写物品信息。

未绑定时按提示进入绑定页，使用虚构手机号，点击获取演示验证码并输入 `123456`。不会发送真实短信。页面切换会保留发布草稿，刷新不保留未提交草稿。

发布照片支持 PNG/JPG/WebP，最大 2MB。可进入地图选址，点击位置并选择所属区域。填写完成后发布，通过成功页进入详情。

### 2. 浏览、搜索与详情

首页浏览物品便签，或按关键词、品类、地点、起始日期和状态组合筛选。点击便签查看描述、地点、时间与状态。

照片在便签小窗展示，详情不重复展示照片；无照片时便签使用文字描述。蓝星表示寻找中，紫星待认领，黄星已找回，亮橙星已归还。完成状态的便签没有悬停位移，但仍可点击。

### 3. 联系发布者

未认证账号按详情页提示进入认证。使用虚构姓名、9位学号和演示学生证图片，不要上传真实证件。提交后为待审核，不代表通过；结果页提供演示审核状态切换。

认证通过后查看联系方式，点击复制；浏览器不允许复制时按提示手动复制。此处提供联系方式，不包含真实聊天或短信服务。

### 4. 确认交接与赠送玫瑰

切换为发布者，从自己的物品进入交接流程，选择对方账号并确认。寻物完成变为“已找回”，招领完成变为“已归还”。其他账号不能通过正常界面替发布者确认。

失主在符合条件的完成记录中点击“赠人玫瑰”，填写感谢语并赠送，或跳过。切换到对应拾主账号，在星册查看收到的盆栽玫瑰、赠送者、日期与感谢语。每条交接最多赠送一次，不能赠送给自己。

玫瑰颜色在赠送时从红、蓝、黄、粉、橙、紫中随机确定并保存，刷新不会重新抽色。

### 5. 校园星图与导航

首页可进入校园星图，发布表单也可进入地图选址。地图为校园插画，位置是图片百分比坐标；定位按钮演示失败提示，不采集真实定位。

页脚展开北斗七星预览导航，可进入首页、搜索、详情、发布、星册、归还、致谢。窄屏可横向滚动导航。涉及物品的页面使用当前选中的记录；绑定、认证等辅助页面由业务入口进入。

## 自动测试

仅运行测试需要 Node.js，建议使用 **24.x LTS**。在包含 `package.json` 的项目根目录打开终端，执行：

```sh
node -v
node --test
```

不需要执行 `npm install`。如果终端找不到 `node`，检查安装与 PATH，安装后重新打开整个终端窗口。

当前提供的 `tests/pages.test.js` 包含23项测试，直接加载 `app.js`，通过轻量 DOM 替身检查页面渲染、输入校验、组合筛选、账号隔离、权限、状态转换、玫瑰约束及核心流程。实际通过数量以运行输出为准。

## 数据与演示限制

- 数据仅保存在当前浏览器的本地存储中，无服务器、无跨设备同步。同一浏览器里的三个账号共用物品数据，但分别显示个人状态与所属记录。
- 清除浏览器数据可能丢失本地发布及玫瑰记录。移动本地文件、切换浏览器或改用部署网址，也可能使用不同的存储环境。
- 账号、短信、认证与定位均为模拟；前端权限不具备真实安全保护能力，不适合直接作为真实校园服务。
- 请勿填写真实证件资料。认证图片不持久保存，发布照片会占用浏览器存储空间。
- 即使部署在线网址，各访问者也不会自动看到彼此在不同设备上发布的信息。
